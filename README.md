# Morpho Studio

Next.js 14 agency landing page using the App Router, TypeScript, Tailwind CSS,
shadcn/ui-style primitives, Framer Motion, and next-themes.

## Run Locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Content

All visible site copy, navigation, team data, services, project labels, and image
paths are centralized in `lib/data.ts`.

## Scripts

```bash
npm run build
npm run start
npm run lint
```
